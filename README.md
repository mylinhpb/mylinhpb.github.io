# My Linh Phung - Technical Writer Portfolio

A clean, elegant portfolio showcasing technical documentation, tutorials, and guides.

## Built With

- Jekyll
- GitHub Pages
- Custom CSS with a warm, elegant color palette

## Local Development

```bash
bundle install
bundle exec jekyll serve
```

Visit `http://localhost:4000` to view the site locally.

## Adding New Articles

1. Create a new markdown file in `_articles/` directory
2. Add front matter with title, description, date, and tags
3. Write your content in Markdown
4. Commit and push - GitHub Pages will automatically deploy!

## Color Palette

- Primary: #916953 (Warm brown)
- Secondary: #cf8e80 (Rose gold)
- Accent: #fcb5b5 (Soft pink)
- Light: #fcddf2 (Light pink)
- Background: #faf6f6 (Off-white)
